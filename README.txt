Monsoon Music Player (Python)

1. Put your audio files in the songs folder.
2. For song artwork, put an image with the same filename next to the song:
   Example: song.mp3 + song.jpg
3. You can also use cover.jpg, folder.jpg, or album.jpg as a fallback.
4. Double-click start.bat.
5. Open http://localhost:8000

No Node.js or npm is required.
The server supports HTTP Range requests for seeking.


Artwork: The player now always shows a built-in vinyl record image and rotates it while playing. Song cover files are ignored.
